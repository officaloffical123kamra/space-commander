Пауза

Управление

Сенсорный экран

  • Тап по своему юниту — выделить (двойной тап — всех таких же)
  • Тап по земле / врагу / минералам — приказ выделенным
  • Тап по зданию — выделить здание; затем тап по земле — точка сбора
  • Провести пальцем — двигать камеру, два пальца — масштаб
  • Кнопки справа — армия, рабочие, рамка, сброс выделения
  • Миникарта — коснитесь, чтобы перейти

Камера

  • W / A / S / D или стрелки — движение камеры
  • Колесо мыши — приближение / отдаление
  • Клик по миникарте — камера прыгает туда

Выделение

  • ЛКМ — выделить юнита / здание
  • Двойной ЛКМ — выделить всех таких же на экране
  • Зажать ЛКМ и тянуть — рамка выделения
  • 1-9 — выбрать группу
  • Ctrl + 1-9 — сохранить выделение в группу
  • Двойной клик по цифре — камера к группе

Приказы

  • ПКМ — идти / атаковать / добывать
  • ПКМ по своему зданию — идти к нему
  • ПКМ при выделенном здании — точка сбора
  • Q — режим атаки (потом ЛКМ по цели)
  • S — стоп
  • T — осадный режим (танк)
  • V — трансформация (викинг)
  • X — super-shot (призрак)
  • ESC — пауза

Об игре

SPACE COMMANDER — RTS-прототип в стиле StarCraft 2.

Выживание — отбивайте бесконечные волны врагов, которые идут со всех 4 сторон карты. Каждые 5 волн приходит босс.

Игра по сети (только дома, по Wi-Fi, до 4 игроков на ПК и телефонах) — вместе против волн или друг против друга.

Управляйте рабочими, стройте здания, производите армию и уничтожьте базу противника.

На телефоне: тап — выделить или отдать приказ, палец — камера, два пальца — масштаб.

  • ЛКМ — выделить юнита / здание
  • ПКМ — идти / атаковать / добывать
  • Q — атака, S — стоп
  • T — осада, V — форма
  • 1-9 — группы, Ctrl+1-9 — сохранить
  • ESC — пауза
